# Primary sources and their use

- **gmtkn55**. Goerigk et al. (2017) constructed GMTKN55 for main-group thermochemistry, kinetics and noncovalent interactions. Define a chemically relevant subset before analysis. The authors maintain corrected data and weighting information. [Paper](https://doi.org/10.1039/C7CP04913G) · [Author-maintained data](https://www.chemie.uni-bonn.de/grimme/de/software/gmtkn55)
- **quest**. Loos et al. (2025) present state-resolved theoretical best estimates of vertical excitations. Preserve the state assignment, basis and quality flag of the chosen entry. [Paper](https://doi.org/10.1021/acs.jctc.5c00975)
- **solid-eos**. Lejaeghere et al. (2016) compare PBE energy–volume curves across implementations and potentials for elemental crystals. Inter-code agreement assesses precision at the chosen physical model. [Paper](https://doi.org/10.1126/science.aad3000)

Record the exact data revision, geometry files and reference values used for a real run. This module distributes original guidance and no dataset or calculated outcomes.
