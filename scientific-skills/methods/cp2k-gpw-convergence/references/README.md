# Scientific sources

## quickstep

Kühne et al. (2020) describe Quickstep, the orbital and density representations, and the implementation of energies and forces. [Journal of Chemical Physics 152, 194103](https://doi.org/10.1063/5.0007045)

## molopt

VandeVondele and Hutter (2007) report the construction and tests of molecularly optimized Gaussian orbital basis sets. [Journal of Chemical Physics 127, 114105](https://doi.org/10.1063/1.2770708)

## gth

Krack (2005) tabulates GTH-type pseudopotentials by element and target gradient-corrected functional for H through Kr. [Theoretical Chemistry Accounts 114, 145](https://doi.org/10.1007/s00214-005-0655-y)

## grid-tutorial

The CP2K 2025.1 silicon example isolates the two grid settings using a frozen SCF step. Its inputs are specific to that demonstration. [CP2K cutoff tutorial](https://manual.cp2k.org/cp2k-2025_1-branch/methods/dft/cutoff.html)

## grid-keywords

The CP2K 2026.2 input reference defines the units and roles of the multigrid settings. [MGRID reference](https://manual.cp2k.org/cp2k-2026_2-branch/CP2K_INPUT/FORCE_EVAL/DFT/MGRID.html)
