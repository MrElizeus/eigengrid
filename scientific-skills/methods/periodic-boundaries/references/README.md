# Scientific sources

## cp2k-cell

CP2K 2025.2, CELL. Geometry periodicity controls pair images. [CELL manual](https://manual.cp2k.org/cp2k-2025_2-branch/CP2K_INPUT/FORCE_EVAL/SUBSYS/CELL.html)

## cp2k-poisson

CP2K 2025.2, POISSON. Solver choices depend on dimensionality, orientation and density at the boundaries. [POISSON manual](https://manual.cp2k.org/cp2k-2025_2-branch/CP2K_INPUT/FORCE_EVAL/DFT/POISSON.html)

## surface-dipole

Bengtsson (1999) derives the artificial vacuum field and dipole correction for an asymmetric neutral slab in a repeated cell. [Physical Review B 59, 12301](https://doi.org/10.1103/PhysRevB.59.12301)

## bulk-defect

Freysoldt, Neugebauer and Van de Walle (2009) demonstrate an electrostatic finite-size correction for charged bulk defects in dielectric hosts. [Physical Review Letters 102, 016402](https://doi.org/10.1103/PhysRevLett.102.016402)
