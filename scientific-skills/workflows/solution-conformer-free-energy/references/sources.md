# Primary sources

## Pracht, Bohle and Grimme (2020), low-energy conformer sampling

Develops an ensemble search methodology. Completeness must be assessed for each new system. [Source](https://doi.org/10.1039/C9CP06869D)

## Marenich, Cramer and Truhlar (2009), SMD

Specifies the continuum transfer model and conventions, including the pressure-to-concentration correction in a thermodynamic cycle. [Source](https://doi.org/10.1021/jp810292n)

## Grimme (2012), binding thermodynamics

Uses a low-frequency treatment motivated by free rotation in supramolecular binding thermodynamics. [Source](https://doi.org/10.1002/chem.201200497)

## ORCA 6.1.1 manual, thermochemistry §4.7

Describes the ideal-gas thermochemistry model, quasi-RRHO options and defaults. Verify the installed release and the output conventions. [Source](https://orca-manual.mpi-muelheim.mpg.de/contents/structurereactivity/thermochemistry.html)
