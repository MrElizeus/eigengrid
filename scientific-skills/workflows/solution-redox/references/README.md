# Sources and their scope

## REDOX-BENCH

Benchmarks first and second reductions against measurements in DMF and documents charge-state and solvation-dependent systematic errors. These are scope-specific data. [Elhajj and Gozem (2024), first and second reductions of quinones in an aprotic solvent](https://doi.org/10.1021/acs.jctc.4c00602)

## REF-SCALE

Shows how electron and solvent conventions enter absolute reference conversions. [Isse and Gennaro (2010), absolute potential of the standard hydrogen electrode and interconversion between solvents](https://doi.org/10.1021/jp100402x)
