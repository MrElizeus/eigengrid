# Source notes

- **slurm-gres**. SchedMD, Generic Resource Scheduling, “Running Jobs” and “GPU Management”. Resource requests and job-step device visibility. [Manual](https://slurm.schedmd.com/gres.html)
- **slurm-sbatch**. SchedMD, sbatch, “Description” and working-directory options. Submission acknowledgement, pending allocation and file movement. [Manual](https://slurm.schedmd.com/sbatch.html)
- **slurm-sacct**. SchedMD, sacct, “Description” and accounting fields. Job and step records depend on site accounting configuration. [Manual](https://slurm.schedmd.com/sacct.html)
- **orca-parallel**. FACCTs, ORCA 6.1 manual §2.5. Driver invocation, parallel modules and scratch. [Manual](https://www.faccts.de/docs/orca/6.1/manual/contents/essentialelements/parallel.html)
- **orca-memory**. FACCTs, ORCA 6.1 tutorial, “Memory Settings”. Per-process memory budgeting. [Tutorial](https://www.faccts.de/docs/orca/6.1/tutorials/first_steps/memory.html)
- **cp2k-runtime**. CP2K developers, CP2K 2026.2 troubleshooting. MPI library mismatch, hybrid layouts and memory failures. [Manual](https://manual.cp2k.org/cp2k-2026_2-branch/getting-started/troubleshooting.html)

The readiness record and pilot acceptance gates are EigenGrid protocol design. The manuals describe software behavior and do not supply site qualification.
