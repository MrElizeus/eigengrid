# Sources and their scope

## TD-CT

Demonstrates strong errors of common approximations for long-range CT transitions. [Dreuw and Head-Gordon (2004), Failure of TDDFT for long-range charge-transfer states](https://doi.org/10.1021/ja039556n)

## TD-DOUBLES

Explains the frequency dependence required when a double excitation mixes with a single. [Maitra et al. (2004), Double excitations within TDDFT linear response](https://doi.org/10.1063/1.1651060)

## NTO

Provides the transition-density representation for electronic assignments. [Martin (2003), Natural transition orbitals](https://doi.org/10.1063/1.1558471)

## ORCA-TD

Documents response choices and NTO analyses. Available combinations depend on the engine build. [ORCA 6.1 manual, excited states via RPA, CIS, TD-DFT and SF-TDA](https://www.faccts.de/docs/orca/6.1/manual/contents/spectroscopyproperties/tddft.html)
