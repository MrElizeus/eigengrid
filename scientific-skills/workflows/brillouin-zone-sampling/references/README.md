# Scientific sources

## special-points

Monkhorst and Pack (1976) construct weighted reciprocal-space sampling for Brillouin-zone integrals. [Physical Review B 13, 5188](https://doi.org/10.1103/PhysRevB.13.5188)

## thermal-dft

Mermin (1965) gives the variational framework for electron systems in thermal equilibrium. [Physical Review 137, A1441](https://doi.org/10.1103/PhysRev.137.A1441)

## kpoints

The CP2K 2025.2 reference defines mesh scheme, coordinates, weights and constraints on grouping processes. [KPOINTS reference](https://manual.cp2k.org/cp2k-2025_2-branch/CP2K_INPUT/FORCE_EVAL/DFT/KPOINTS.html)

## smear

The CP2K 2025.2 reference specifies occupation smearing and the units for electronic temperature. [SMEAR reference](https://manual.cp2k.org/cp2k-2025_2-branch/CP2K_INPUT/FORCE_EVAL/DFT/SCF/SMEAR.html)
