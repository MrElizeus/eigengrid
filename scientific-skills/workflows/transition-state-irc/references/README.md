# Sources and their scope

## IRC

Defines the reaction coordinate connecting a saddle to its neighboring valleys. [Fukui (1981), The path of chemical reactions — the IRC approach](https://doi.org/10.1021/ar00072a001)

## ORCA-IRC

Documents the two path directions, Hessian handling, consistent method/basis and trajectory outputs. [ORCA 6.1 manual, intrinsic reaction coordinate](https://www.faccts.de/docs/orca/6.1/manual/contents/structurereactivity/irc.html)
