# Sources and their scope

## BB-CP

Introduces the counterpoise procedure. [Boys and Bernardi (1970), The calculation of small molecular interactions by the differences of separate total energies](https://doi.org/10.1080/00268977000101561)

## S66

Defines a fixed-monomer interaction benchmark for multiple noncovalent interaction classes. Conform to the reference geometry and edition for any actual comparison. [Řezáč, Riley and Hobza (2011), S66 interaction benchmark](https://doi.org/10.1021/ct2002946)

## ORCA-CP

Distinguishes explicit ghost-fragment and geometrical corrections, and illustrates energy bookkeeping. [ORCA 6.1 manual, counterpoise corrections](https://www.faccts.de/docs/orca/6.1/manual/contents/essentialelements/counterpoise.html)
