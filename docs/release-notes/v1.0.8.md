# EigenGrid 1.0.8

Amber result publication closes verified staging descriptors before unlinking
temporary files. This prevents NFS from retaining an extra link that causes the
strict single-link check to reject completed results. Interrupted publication and
stale staging cleanup use the same ordering. Hash, ownership and link-count
checks remain enforced.

The worker checks writer identity, protected configuration and existing project
directories before starting the engine. Diagnostics report bounded phase,
category and errno labels without exposing arbitrary exception text or secrets.
Model budget exhaustion has a specific sanitized state and preserves uncertain
usage reservations.

New operator tools capture qualification PostgreSQL, referenced artifact stores
and bounded agent journals, with a separate configuration recovery bundle.
Verification checks source identity, hashes, membership and recovered client
authority. These tools require site installation and protected configuration;
publishing this release does not activate backup timers.

Online database, journal and configuration captures are not atomic across
components. Restoration remains quarantined and never resumes sessions or
scientific submissions automatically. Worker backup copies are not offsite backups.

This patch does not change database migrations, scientific approvals or dispatch
policy. Installation qualification and protocol-level scientific acceptance remain
separate from software verification.
