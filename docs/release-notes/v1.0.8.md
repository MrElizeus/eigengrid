# EigenGrid 1.0.8

The mission agent now reports a model gateway's budget-exhaustion error as a budget
boundary instead of a generic inference failure. The error message is fixed and does
not expose provider details. If usage is uncertain, its existing reservation remains
fenced; this update does not release or rewrite historical reservations.

Operational backup support captures qualification database state, immutable artifacts
and bounded journal snapshots for recovery checks. Online snapshots are not a single
atomic view of all services; restoration requires the documented quarantine and
verification procedure before reopening effects.

These changes improve software operation and recovery. They do not establish scientific
acceptance, change protocol maturity or authorize scientific dispatch.
