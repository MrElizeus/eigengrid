# EigenGrid 1.0.4

This release improves operational qualification, shared model compatibility and
scientific evidence handling before site-specific scientific validation.

- OpenCode model pricing supports cache-write prices indexed by duration and
  preserves conservative bounds across context tiers. Malformed rates fail before
  inference instead of being treated as zero cost.
- Operator file reads verify the opened file descriptor and refuse nonregular
  files, including substitution with a FIFO. The agent/tool integration regression
  checks that a real scientific output reaches the next inference step.
- Production qualification v2 binds policy, artifact root and the exact protected
  site configuration to recorded fixtures, reviewer and evidence hashes. Version 1
  reports cannot admit this release. The enabled Head health path constructs the
  execution gateway and postprocessing dependencies before reporting readiness.
- Operations scripts provide PostgreSQL plus immutable CAS backups, integrity
  checks and explicit restoration into an empty disposable database. Storage checks
  detect reserve exhaustion and missing data mounts without deleting files.
- A private catalog inventory records exact protocol versions and hashes together
  with separate fields for implementation, numerical checks and scientific acceptance.

No molecular parameters, catalog maturity or scientific acceptance decisions are
changed. Deployment requires fresh site qualification. Engine regressions and
software tests do not validate an entire scientific protocol family.
