# EigenGrid 1.0.3

This update adds administrator-owned default model configuration and an explicit
production admission path for the canonical scientific Head.

- CLI, TUI, planning and mission inference can load `/etc/eigengrid/llm.json`.
  Protected site defaults are replaced by a user's complete private selection;
  credentials are never merged across endpoints. `model-config` reports the source
  and selected model without printing credentials or calling a provider.
- Slurm 26.05 accounting uses data_parser/v0.0.45, preserves full exit codes and
  validates native/text identity and state. Captured 26.05.5 scheduler probes cover
  success, failure, exit 137, cancellation and timeout. Existing 23.11 support remains.
- Production dispatch can be admitted through a protected configuration bound to
  the installed release, MD policy, scheduler version and site qualification report.
  Startup requires matching signing authority, project memberships, private artifact
  storage and postprocessing configuration. Default installations stay in standby
  until their complete installed execution and recovery path has passed.
- Concurrent artifact publication waits a bounded interval for the publisher's
  durable disk synchronization before retrying full single-link/digest validation.
  Persistent extra links remain invalid. The restart regression uses an explicit
  completion gate rather than assuming the launcher exits within one second.

No database migrations or molecular scientific settings are changed. Shared model
credentials must be provisioned by the administrator. Scheduler fixtures and
software tests do not establish a scientifically accepted campaign.
