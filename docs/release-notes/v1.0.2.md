EigenGrid 1.0.2 completes interactive scientific campaign planning and fixes recovery
from ordinary command failures in the CLI/TUI operator.

## Interactive scientific planning

- `/plan <objective>` now invokes the configured model with the conversation's known
  inputs and parameters. It searches relevant installed protocols, inspects exact
  versions and dependencies, and follows paginated procedures before citing them.
- The agent can ask focused questions with explained options, a justified recommendation
  and free-text input. It waits for actual answers and incorporates them into the
  campaign. Cancellation does not invent a default or create an empty plan.
- Proposals include assumptions, scientific decisions and alternatives, ordered stages,
  inputs and outputs, parameters, resource estimates, acceptance criteria, recovery,
  risks and remaining gaps. Long plans can be assembled in sections without increasing
  the configured per-response token limit.
- Complete proposals are displayed and saved as immutable revisions. Follow-up messages
  remain in planning mode; `/plan off` explicitly returns to the ordinary operator.
- The CLI uses the same planner. Successful `--json` output preserves the scientific
  plan artifact envelope; unanswered noninteractive questions return `needs-input`.

## Scientific inputs and provenance

- Planning can search public RCSB structure metadata and download structures, ligands,
  documents and metadata from public HTTPS sources into private campaign storage.
- Each asset records its original and final URL, acquisition time, size and SHA-256.
  Reads verify the retained hash. Acquisition bounds file size, time and redirects,
  rejects credential/private-network URLs and cannot overwrite original inputs.
- PDB inspection reports coordinate records, chains and hetero-residue names. These
  observations do not establish ligand identity, biological assembly or simulation
  readiness. PDFs are retained with provenance; PDF text extraction is not included.

## Operator reliability

- A missing executable previously returned `exitCode: undefined` with a success flag.
  Canonical journal serialization then failed with “Tool effect needs authoritative
  reconciliation,” preventing the model from trying an available alternative.
- Missing commands, nonzero exits, signals and timeouts now return bounded diagnostics
  to inference. The TUI reports the command outcome instead of a generic completion.
- The model can inspect available alternatives, such as `python3` when `python` is
  absent. Timeouts and signals still require checking partial effects before retrying;
  genuinely unconfirmed effects retain the existing reconciliation boundary.

## Compatibility and installation

The Linux x64 distribution includes six native executables, the public scientific
catalog, the Python wheel, dependency notices and retrieval setup examples. Download
`eigengrid-1.0.2-linux-x64.tar.gz`, `release.json`, `SHA256SUMS` and `validation.json`
together. Verification binds package bytes to the source commit and CI run.

Existing database migration bytes and scientific execution approvals are unchanged.
The authenticated backend API and CLI/TUI remain the supported interfaces; the web
interface is still separate. Model weights and scientific engines are installed
separately.

The catalog-preserving installation and private site composition procedures introduced
in 1.0.1 remain available. Public release assets contain only the public catalog.
Private protocols remain in the site's external catalog and are not uploaded to GitHub.
Review the selected combined catalog and its digest before activation. This release
does not itself update a cluster or expand the release controller's installation policy.

## Validation and limits

Publication requires passing GitHub-hosted static checks, native build and installed
tool smoke checks, reproducible packaging, TypeScript tests with disposable PostgreSQL,
Python regressions and public distribution hygiene checks.

Planning is a proposal workflow, not scientific approval. It does not run arbitrary
shell, SSH, Slurm, installations or calculations, even with Full Access selected.
Scientific dispatch qualification and campaign acceptance remain separate installation
decisions. Downloading a paper does not mean its contents were read or validated.
