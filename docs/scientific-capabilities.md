# Scientific capabilities and limits

The public distribution supplies 15 basic draft knowledge entries for molecular
structures, charge/spin, basis selection, convergence, molecular DFT, dispersion,
continuum solvation, geometry optimization, frequencies, diagnostics and validation.
They have no expert-review or scientific-qualification claim. See `publication.json`
for the exact allowlist and `publication-catalog.json` for reviewed file hashes.

The runtime provides generic typed interfaces for preparation, staged dynamics,
replicas, restart lineage, byte inspection, parsing and durable execution. Engine
adapters and schemas describe software capabilities, not an approved scientific
recipe. External engines, licensing, site configuration and numerical validation
remain the operator's responsibility. Domain-specific study profiles and advanced
protocol catalogs are not included.

The public example is a small peptide preparation contract. Test fixtures are
synthetic or minimal parser examples; they do not establish scientific acceptance.
A zero process exit, normal termination or low structural deviation is insufficient
to approve a scientific result. Decisions and approvals must bind exact systems,
inputs, versions, parameters and observed evidence.

Users can inspect schemas without a model or compute service. Read
[external catalog configuration](catalogs.md) before supplying an additional
knowledge corpus. Unsupported engine capabilities remain unavailable even when a
catalog describes them. The installed software does not contain engine binaries,
force-field libraries, production credentials or unpublished study results.
